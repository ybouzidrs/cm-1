# Histoire · Période 1 : « Le temps des rois » (Mérovingiens)

## Évaluation à imprimer

Dossier `evaluation/` :
- `evaluation-sujet.pdf` : le sujet pour l'élève (3 pages A4, noté sur 20, avec la grille de compétences)
- `evaluation-corrige.pdf` : le corrigé et le barème pour l'enseignant (4 pages A4), séparé du sujet
- les versions `.html` des deux documents et `generer.py`, le script qui les produit (il reprend les styles de `sciences/periode-1/evaluation/generer.py`)

Contenu : la frise des grandes périodes (476, chute de l'Empire romain), Clovis agrandit le royaume des Francs (peuples de la Gaule en 481, Paris capitale en 511, les Burgondes), le vase de Soissons, Clovis premier roi catholique (481, 496, Reims, Tolbiac, Mérovingiens), les personnages (Clotilde, Rémi, Dagobert, Brunehaut), l'héritage (loi salique, prix du sang, Dagobert, violence), après Clovis (511, partage, rois fainéants) et le vocabulaire (monarchie, royaume).
