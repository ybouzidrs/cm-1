# Anglais · Période 1 : bilan

## Évaluation à imprimer

Dossier `evaluation/` :
- `evaluation-sujet.pdf` : le sujet pour l'élève (3 pages A4, noté sur 20, avec la grille de compétences)
- `evaluation-corrige.pdf` : le corrigé et le barème pour l'enseignant (3 pages A4), séparé du sujet
- les versions `.html` des deux documents et `generer.py`, le script qui les produit (il reprend les styles de `sciences/periode-1/evaluation/generer.py`)

Contenu, d'après le programme du bilan : les 4 pays du Royaume-Uni sur une carte (nom en anglais, capitale, emblème), se présenter en 3 phrases, les nombres jusqu'à 20, les jours de la semaine, les couleurs et le vocabulaire d'Halloween.
